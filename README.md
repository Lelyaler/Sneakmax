# Sneakmax — Интернет-магазин оригинальных кроссовок

[Демонстрация сайта](https://lelyaler.github.io/Sneakmax/)

Современный адаптивный веб-магазин брендовой спортивной и повседневной обуви (Nike, Adidas, New Balance, Asics, Jordan, Converse, Salomon).

## Особенности проекта

- **Главный промо-блок**: динамический баннер с актуальными силуэтами и быстрым переходом к подбору.
- **Интерактивный квиз**: пошаговый опрос для персонального подбора кроссовок по стилю, размеру и бюджету.
- **Каталог товаров**:
  - Фильтрация по ценовому диапазону (двусторонний ползунок `noUiSlider`).
  - Фильтрация по полу (мужской / женский) и размерам обуви.
  - Адаптивная сетка карточек товаров и мобильная панель фильтров.
- **Карточка товара и быстрый просмотр**:
  - Модальное окно с детальными характеристиками и галереей ракурсов (`Swiper`).
  - Выбор размера и добавление в корзину.
- **Корзина заказов**:
  - Выпадающая мини-корзина в шапке и полноэкранное модальное окно оформления.
  - Подсчёт общей суммы, управление количеством и удаление позиций.
- **Интерактивная карта и контакты**:
  - Карта локации шоурума и кнопки открытия маршрутов в Яндекс Карты, 2ГИС и Google Maps.
- **Оптимизация и доступность**:
  - Высокие показатели Core Web Vitals и Mobile Lighthouse (FCP < 1.0s, доступность 100/100).
  - Поддержка клавиатурной навигации и ARIA-атрибутов.

## Стек технологий

- **HTML5** (семантическая вёрстка по методологии БЭМ, поддержка микроформатов и Open Graph)
- **CSS3** (SCSS, Flexbox, Grid, адаптивная вёрстка Mobile-First, кастомные анимации)
- **JavaScript (ES6+)** (модульная архитектура, фильтрация данных, управление состоянием корзины)
- **Библиотеки**: Swiper, noUiSlider, GraphModal, wNumb
